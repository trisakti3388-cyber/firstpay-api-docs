ENTERPRISE INTEGRATION GUIDE

FIRSTPAY Merchant API Platform

FIRSTPAY provides a merchant API suite for deposit, withdrawal, transaction status checking, callback notifications, and balance inquiries. The platform is designed for enterprise integration workflows that require clear signature validation, structured request handling, and reliable operational messaging.

Base API https://api.dsfirstpay.com/API
Credential Model

Merchant ID with Secret Key generated from back office.

Transport & Security

JSON POST requests with MD5 request signature validation.

Security

Authentication & Signature Model

All FIRSTPAY requests require an MD5 signature generated from ascending-sorted request parameters, followed by token={secretkey}. This signature is mandatory for request validation across all supported merchant operations.

Signature = MD5(field_1=value_1&field_2=value_2&field_x=value_x&token={secretkey})
